# issue にする依頼

オーナーがこのセッションで、次の直しを issue にするよう頼んだ。作者はオーナーで、新しい issue である。
この記録の事実は、記録を書いた時点で確かめ済みである。リポジトリのコードはそのあと変わっているので、コードと突き合わせ直さずに、この記録のとおりに書く。

- 内容：Slack のスレッドで、返信の送信に失敗したあと、返信欄の文が消える。要件 S-6 の節に、失敗したら文を残すと既に書いてある（バグ）。
- 再現：一時的な spec で `slack_reply` を失敗させると、返信欄が空になることを確かめた（実画面の WKWebView、コマンドはモック）。
- 直す場所の計画：`ts/slack-thread.ts` を直し、`e2e/specs/slack-thread.e2e.ts` に it を足す。順は ts、spec。ほかのファイルは触れない。
- 画面の見た目は変えない。ポイントは 1 から 3 のどれかとして構わない。
